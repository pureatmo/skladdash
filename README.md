# ABCD закупки

Streamlit-дашборд для загрузки продаж и остатков, ABCD-классификации SKU и расчета рекомендуемого заказа поставщикам.

## Запуск

```powershell
cd D:\Projects\test-codex\inventory_abcd_dashboard
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

По умолчанию история хранится в `data/inventory_history.sqlite`.

Для другого пути:

```powershell
$env:INVENTORY_DB_PATH="D:\inventory-data\inventory_history.sqlite"
python -m streamlit run app.py
```

## Входные файлы

Нужно загрузить 4 Excel-файла:

- продажи USA, лист `Export`
- продажи WW, лист `Export`
- остатки USA
- остатки WW

Ключ SKU: `рынок + сидбанк + продукт + упаковка`.

## Расчет

ABCD считается отдельно внутри каждого рынка по выбранной метрике: выручка, маржа или количество. Пороги по умолчанию:

- A: до 80% накопленной доли
- B: до 95%
- C: до 99%
- D: остаток и SKU без спроса

Прогноз дневного спроса:

```text
если есть текущие продажи и история:
  прогноз = продажи_в_день * (1 - вес_истории) + исторический_спрос_в_день * вес_истории
если есть только текущие продажи:
  прогноз = продажи_в_день
если есть только история:
  прогноз = исторический_спрос_в_день
```

Рекомендуемый заказ на 3 месяца вперед:

```text
горизонт_закупа = 90 дней
спрос_на_горизонт = прогноз_в_день * горизонт_закупа
страховой_запас_шт = прогноз_в_день * страховой_запас_дней
целевой_остаток = спрос_на_горизонт + страховой_запас_шт
к_заказу = max(0, целевой_остаток - текущий_остаток)
```

Опционально можно ограничить заказ только SKU ниже точки заказа:

```text
точка_заказа = прогноз_в_день * (срок_поставки_дней + страховой_запас_дней)
```

## Онлайн

Проект проще всего поднять как Streamlit-приложение на VPS, Render, Railway или Streamlit Cloud. Для надежной истории нужен постоянный диск или внешний путь к SQLite через `INVENTORY_DB_PATH`; на хостингах с эфемерной файловой системой история может сбрасываться при пересборке.

### Render / Docker

В проект добавлены `Dockerfile` и `render.yaml`. При деплое через Render база истории хранится в `/data/inventory_history.sqlite`, а `/data` должен быть подключен как persistent disk.

Локальная Docker-проверка:

```powershell
cd D:\Projects\test-codex\inventory_abcd_dashboard
docker build -t inventory-abcd-dashboard .
docker run --rm -p 8501:8501 -e INVENTORY_DB_PATH=/data/inventory_history.sqlite inventory-abcd-dashboard
```

После деплоя пользователи открывают публичный URL и загружают Excel-файлы через браузер.
